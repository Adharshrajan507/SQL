This project focuses on analyzing a car sales dataset containing 23,905 records using SQL and Power BI. SQL was used for data cleaning, data manipulation, and querying to extract meaningful business insights related to sales, revenue, profit, car models, brands, customer preferences, and regional performance. Power BI was used to create an interactive dashboard with KPI cards, charts, maps, and slicers to visualize key business metrics and identify sales trends. The project demonstrates practical skills in SQL, data analysis, data visualization, and business intelligence.
